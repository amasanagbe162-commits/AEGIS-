AEGIS: AI Engineering Guard & Inspection System

An open-source toolkit that helps AI coding agents write safer code, then checks their work with real security scanners and tells you honestly what it could and could not verify.

  • Inspect before coding
  • Protect during coding
  • Verify after coding

Three layers, because instructions alone are not enough

An AI agent can ignore its instructions, and cannot prove its own work is safe. AEGIS adds evidence and, where the agent allows it, enforcement.

Advisory

Instructions

Generated rule files for Claude Code, GitHub Copilot, OpenAI Codex and ChatGPT, built from your own policy file. Your existing instruction files are never overwritten.

Evidence

Real checks

Gitleaks, Semgrep, npm audit, OSV-Scanner, tsc and ESLint. A missing tool is reported as skipped, never as clean.

Enforcement

Claude Code hook

Sends Claude back to fix blocking findings before it finishes, at most 3 times by default, so it can never loop forever.

The self-correction loop every agent is told to follow

Never edit a test just to make it pass. Stop at the attempt limit and report what is unresolved.

  1. Detect
  2. Investigate
  3. Diagnose
  4. Correct
  5. Verify
  6. Report

What you get

Project detection

Finds your language, framework and package manager from evidence, and says when it is unsure.

Three protection levels

Standard, advanced and maximum, from personal projects to high-risk applications.

Protection rules

Six rules with unsafe and corrected examples. The examples are run in tests, so the fix is checked, not assumed.

Honest reports

Exit codes 0 clean, 1 findings, 2 invalid, 3 incomplete. A scan with skipped checks is never called clean.

Learning records

Record a mistake once. AEGIS verifies the fix with a real check; only you can approve it.

Signed rule updates

Optional and off by default. Ed25519 signatures, no downgrades, atomic install, no project data sent.

Try it

aegis doctor                           # is my setup OK? changes nothing
aegis init --agent claude-code         # preview, confirm, then create files
aegis scan                             # full report from the real scanners
aegis agents sync --hooks              # optional Claude Code Stop hook
aegis learn add ...                    # remember a mistake; you approve it
