# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link applies to all project spaces.

In short: be respectful, welcoming, and constructive. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

## Reporting

Report conduct concerns privately to the maintainers through GitHub (use the repository's private reporting option or contact the repository owner via their GitHub profile). Maintainers will review reports promptly and keep reporters' details confidential.
