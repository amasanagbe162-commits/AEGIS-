# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the impact.

You can expect an acknowledgement as soon as a maintainer is available. This is a volunteer project, so no response-time guarantee is made.

## Scope

AEGIS is in early development. Reports about the tooling, CI configuration, and (once they exist) the parser, scanner wrapper, rule updates, and generated files are welcome.

## Supported versions

No stable release exists yet. Only the `main` branch is supported.
